# Parity slice E2: Danish boards (jobindex, jobnet, jobdanmark)

1. Files read completely: for each of `.agents/skills/jobindex-search`, `jobnet-search`, `jobdanmark-search` (below `JI`, `JN`, `JD`): SKILL.md, README, every `cli/src/**/*.ts`, every `cli/tests/*.ts`; plus JI/url-reference.md. Live probes (2026-10-19) are in the board notes, not cited as rows.
2. Row count: 139 (table rows, excluding headers).
3. Not expressible in the matrix: the per-board endpoint/selector knowledge (see `boards/jobindex.md`, `boards/jobnet.md`, `boards/jobdanmark.md`); the original's `--format table|plain` renderers and bunli CLI plumbing are deliberately not ported (the loop calls adapters as functions).
4. Surprises: (a) the originals have no robots.txt check and jobindex's live robots.txt disallows the `page=`, `sort=`, `jobage=` params the CLI always sends; jobnet's robots.txt redirects to a login (307); (b) jobdanmark's "not found" detection is dead against the live site (missing slug 301-redirects to a 200 search page) and live pages have no JSON-LD; (c) a fresh jobindex detail page matches neither parsed shape, so company/location/deadline would come back null; (d) several guarantees are prose-only: jobnet "do not combine --region and --postal-code", "BestMatch requires a search string", jobindex "jobage is 1/7/14/30/9999" (schema accepts any integer >= 1), and sort/order values are unvalidated strings; jobindex's `apiFetch` and its two tests (timeout, retry) cover code the CLI never calls (search uses `htmlFetch`).
5. Contradictions: jobindex url-reference.md says path-based area slugs work, README/SKILL say area filtering does not work and the CLI never builds those paths; jobindex README says detail "follows redirects to the canonical URL" but the code always fetches the rebuilt short URL; jobnet README says `--query` is required in an error example but the flag is `--search-string`.

Legend: `JI` = `.agents/skills/jobindex-search`, `JN` = `.agents/skills/jobnet-search`, `JD` = `.agents/skills/jobdanmark-search`. Cited line numbers are those of the original files. Planned module names: `boards/http` (shared httpx helper), `boards/contract` (shared normalisation and JSON contract), `boards/jobindex`, `boards/jobnet`, `boards/jobdanmark`, `guards` (robots), `search` (client-side filters).
